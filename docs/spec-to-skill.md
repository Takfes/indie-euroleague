## how to merge player data

- we now have data from basketnews-players-stats, basketnews-onoff-stats, dunkest-data and euroleague-fantasy - all in the data folder. the idea is to bring all these data together in a single dataframe/table. the connecting entity across datasets is the player. the first three quote player stats, whilst the euroleague-fantasy one price per player. the resulting dataframe should collect all the datapoints for a player, by source - one line per player. after merging all the info from each of the datasets, there might exist duplicated info - remove that. the position comes from the dunkest dataset (only players missing from dunkest fall back to the basketnews position, then the fantasy one). order the columns by source: player identity first (player_name, team_name, position, season, games_played), then dunkest, then basketnews advanced (player_id and bnadv), then basketnews on/off (bnoo - total first, then offense, then defense), and at the rightmost part the euroleague fantasy price and price_rank. right after the identity columns add found_in (the source datasets where the player was found, comma separated, e.g. "dunk, elf") and found_in_count (how many). players are spelled differently across sources (e.g. "baldwin" vs "baldwin iv", jr/sr/ii/iii/iv suffixes, accents, hyphens, nicknames), so match them tolerating those differences - but never merge two different players (wade baldwin iv, patrick baldwin jr and kamar baldwin stay three rows). the output is an xlsx workbook (data/curated/player_master_table.xlsx), not a csv, with these sheets in order: "Column Guide" (source dataset, column name as in that dataset, explanation in few words - every column of every source once), "Master" (the merged table), then one sheet per source dataset as-is: "Dunkest", "BN Advanced", "BN On-Off" (long format, rows ordered total, offensive, defensive) and "Fantasy Prices". create a skill (.claude/skills) for repeating the above through an agent. also create the resprective python script in the /src folder.

## how to merge team data

- we now have data from basketnews-team-stats and dunkest-defense-positions - both in the data folder, one row per team (20 teams). the idea is to bring the two together in a single dataframe/table. the connecting entity across datasets is the team. basketnews quotes team offense/defense stats (all games, home, away), whilst dunkest quotes what each team concedes per game to guards, forwards and centers. the two sources use different team ids (real madrid is 368 in basketnews and 45 in dunkest) and spell some team names differently ("hapoel shlomo tel aviv" vs "hapoel ibi tel aviv", "maccabi playtika tel aviv" vs "maccabi rapyd tel aviv", "kosner baskonia vitoria-gasteiz" vs "baskonia vitoria-gasteiz", "virtus segafredo bologna" vs "virtus bologna"), so match them tolerating that, with a small explicit crosswalk of the differing names and no fuzzy guessing - but never merge two different teams: the match must be strictly one-to-one, and if a team stays unmatched (or matches twice) the build stops with an error naming the teams on each side and how to fix it. every team is in both sources, so no found_in columns. one line per team, no blanks, rows sorted by team_name. order the columns by source: team identity first (team_name and team_short_name from basketnews, season, the two team ids under distinct names, games played from basketnews), then the basketnews team columns in their existing block order (offense_all, offense_home, offense_away, defense_all, defense_home, defense_away), then the dunkest defense-vs-position columns in their existing position order (guards, forwards, centers). after merging, remove duplicated info (the dunkest team name and season repeat the identity ones). prefix every source column like in the player table (bnteam for basketnews, dunkdvp for dunkest), defined once in the script. the output is an xlsx workbook (data/curated/team_master_table.xlsx), not a csv, with these sheets in order: "Column Guide" (source dataset, column name as in that dataset, explanation in few words - every column of every source once), "Master" (the merged table), then one sheet per source dataset as-is: "BN Team Stats" and "Dunkest Defense vs Position". create a skill (.claude/skills) for repeating the above through an agent. also create the respective python script in the /src folder.
