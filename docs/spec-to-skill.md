## how to get data

- visit this link https://euroleaguefantasy.euroleaguebasketball.net/10/fantasy/2880875/team and parse the dataset with all players that appears on the right. keep track of player name, position, avg fpt, pop and the value in the box (which is price). so you need to focus on the right hand-side and scroll. you don't need to open (click) every item, you just need to capture whatever is readily available in the list (before clicking in the item). you also don't need to worry about the various selectros (position G/F/C/HC nor the rounds T1/T2). keep it generic and all the results will show. save the results in data/euroleague-fantasy folder in a csv format. after successful capture of the data, you may turn the above in a skill using the skill-creator skill and saving that in the local `.claude/skills` folder.

- visit this link https://basketballsphere.com/en/euroleague-fantasy-player-prices/ . i want you to capture the price for all players (guards, forwards, centers) as well as head coaches. prefer API call over DOM scraping. you could scrape once for all players and a second time for the headcoaches - point being no need to scrape separately for the various positions. save the results in data/euroleague-fantasy folder in a csv format. after successful capture of the data, you may turn the above in a skill using the skill-creator skill and saving that in the local `.claude/skills` folder.

- visit this link https://basketnews.com/advanced-stats/leaders/players/25-euroleague/2025?leaders_mode=offensive&leaders_sort=offensive_rating_lineup&leaders_sort_desc=0&leaders_min_gp=5 . i want to create a dataset for all players and all positions for both offense and defense. i am interested in all stages, euroleague, 2025 - all of such options i believe are already encoded in the url i provided. so you need to capture the data by toggling the offense/defense switch as well as the pagination. alternatively you can see if you can capture these data from the underlying API call the webpage is making. save the results in data/basketnews-players-stats folder in a csv format. after successful capture of the data, you may turn the above in a skill using the skill-creator skill and saving that in the local `.claude/skills`.folders

- visit this link https://basketnews.com/advanced-stats/on-off/25-euroleague/2025/33-panathinaikos-aktor-athens . i want to create a dataset for all teams. you need to traverse the team selector at the top so that you capture data for all teams. for each team, you need to then toggle between total/offense/defense so that you capture all kpis. alternatively you can see if you can capture these data from the underlying API call the webpage is making. save the results in data/basketnews-onoff-stats folder in a csv format. after successful capture of the data, you may turn the above in a skill using the skill-creator skill and saving that in the local `.claude/skills` folder.

## how to merge data

- we now have data from basketnews-players-stats, basketnews-onoff-stats, dunkest-data and euroleague-fantasy - all in the data folder. the idea is to bring all these data together in a single dataframe/table. the connecting entity across datasets is the player. the first three quote player stats, whilst the euroleague-fantasy one price per player. the resulting dataframe should collect all the datapoints for a player, by source - one line per player. after mergin all the info from each of the three datasets, there might exist duplicated info - remove that. then at the rightmost part, bring in the data for the price. create a skill (.claude/skills) for repeating the above through an agent. also create the resprective python script in the /src folder.
